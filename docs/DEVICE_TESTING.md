## Android 1.1 여러 기기 / 작은 위젯

- `.env`에 PAT를 넣고 빌드/설치한 뒤 토큰 입력 없이 자동으로 목록과 센서값이 표시되는지 확인합니다. `.env` 변경 후 재빌드/재설치 시 새 설정이 적용되는지도 확인합니다.
- 기기 선택에서 가습기, 공기청정기, 공기청정 팬을 여러 대 선택합니다. 센서가 없는 값은 —, 오프라인인 기기는 오류, 정상 기기는 별도 수신값이 보여야 합니다.
- **Climate · 1×1**을 두 개 추가합니다. 각각 본문을 눌러 다른 첫 번째 기기를 지정하고 값이 서로 독립적인지 확인합니다. 기존 4×3 위젯은 제거한 뒤 다시 추가하거나 크기를 줄입니다.
- **Climate · 1×2**를 추가하고 첫 번째/두 번째 기기를 지정합니다. 2×1로 늘렸을 때 가로 배치, 1×1로 줄였을 때 첫 번째 기기만 표시, 다시 늘리면 두 번째 기기 설정 유지 여부를 확인합니다.
- 기기 이름이 길거나 글꼴 크기를 늘렸을 때 센서값이 겹치지 않는지 확인합니다. 작은 크기에서 수신 시각은 생략될 수 있고, 오래된 데이터/오류는 ! 표시와 색상으로 구분해야 합니다.
- 기기 선택에서 한 기기를 제외하면 해당 기기의 캐시만 없어지고 다른 기기의 캐시는 유지되어야 합니다. 제외된 기기를 가리키던 위젯에 다른 기기값이 임의로 표시되면 안 됩니다.
- 갱신 중 기기 선택을 바꾸고 앱을 다시 열어 이전 요청의 결과가 새 설정을 덮지 않는지 확인합니다.

계측 테스트는 `climate-test`, `widget-layout-test`라는 별도 저장소를 사용해 실제 계정 설정과 센서 캐시를 초기화하지 않습니다.

## Android 1.2 위젯 꾸미기

- 기존 위젯을 눌러 꾸미기를 열고 프리셋을 바꾸면 미리보기에 즉시 반영되는지 확인합니다. 취소하면 실제 위젯은 바뀌지 않아야 합니다.
- 배경과 습도 강조색을 직접 입력하고 불투명도를 조정한 뒤 적용합니다. 다른 위젯의 색상은 유지되어야 합니다.
- 위젯 크기를 줄였다 늘리거나 앱을 다시 실행해도 기기 선택/색상이 유지되어야 합니다.
- 긴 기기명, 1×1, 세로/가로 두 기기에서 숫자가 가운데 있고 테두리에 걸리지 않는지 확인합니다. 시스템 글꼴 130%도 확인합니다.
- 앱의 세 가지 위젯 추가 카드의 크기·간격과 버튼 그림자/글자 정렬을 캡처로 비교합니다.
